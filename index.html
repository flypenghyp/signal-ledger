03

CROSS-READING

资本与代码，
在同一个地方会合

把两份名单叠起来，会出现三组“同一件事、两种证据”的对照。

A / 能力封装

把能力做成可调用单元

资本Dream Labs 把机器人技能做成 $3/小时 API；YGO 把库存做成代理可调用接口。

代码orca 把多个 coding agent 收进一个工作台；Skills 把专业动作打包成可安装单元。

含义：竞争点从“谁的模型强”转向“谁能把能力封装成别人愿意调用、愿意付费的接口”。

B / 接口收费站

代理经济的钱在接口上

资本Azoma 卖“在代理答案里被推荐”，Klarent 卖“可验证的测试”，Deepslate 卖“区域托管的语音”。

​代码MCP / Skills / 本地网关成为事实上的集成协议；谁能接上库存、工具与身份，谁就拿到收费站。

含义：亚洲最缺的不是再做一个 Agent，而是本地 OTA/航司/电商库存的“代理可调用层”与可见度测量。

C / 边界能力

验证与治理成为新预算

资本Beagle 用 7,000 名查勘员喂模型；Elio 自己持牌；XRlabs 不换设备只加软件层。

代码security-audit、rea、AnyPS5 同时升温；但这也是 star 异常最集中的区域。

含义：信任不能靠 star 证明；能写进采购标书的审计、日志、合规报告，才是亚洲的溢价来源。

SELECTED CELL

D 治理与安全 · 日本

高6–12 个月可跑通付费闭环

经济安保 + 金融厅合规；可“咨询 + 工具”打包，客单价高、决策链短。

建议动作：以“AI 利用ガバナンス”咨询 + 审计日志/水印工具切入，先做 2 个金融或制造标杆。

PRIORITY

D → A → C，不是 A → B → C

先卖治理与安全（不依赖语言、监管越严越受益），再用编码 Agent 做 PLG 获客，最后用垂直 Agent 收大单。通用 memory/MCP 中间件不做——它大概率是云厂商的一个功能。

  1. 01治理与安全日本 / 新加坡 / 韩国（2027 加码）
  2. 02编码与软件生成PLG 获客，企业版变现
  3. 03垂直行业 Agent做接口层，不再做行业应用

05

THE CALL

如果只做三件事

把研究变成动作，按“验证—试点—定型”三段推进。默认团队 3–8 人、能在日本/新加坡合法签约。

  1. 第 1–2 周

    选定治理切口

    Agent 审计日志 / 数据驻留 / 内容标识三选一；做日本 + 新加坡合规对照表；列 3 个目标客户。

  2. 第 3–6 周

    三个设计伙伴 PoC

    日本制造 SIer、新加坡跨国企业区域总部、印度 GCC 各 1 个；同时用开源 Skills / 多 Agent 工作台跑内部效率试点，记录 token 成本。

  3. 第 7–12 周

    定型与复制

    形态定为 API + 私有化部署；定价按结果/用量；对 Dream Labs 与 YGO 做亚洲可迁移性尽调，形成合作/代理/对标结论。

三个“不要做”

  • 不做通用 memory / MCP 中间件。在亚洲它大概率是云厂商的一个功能，不是一家公司。
  • 不做“泛亚洲一套产品”。日本、韩国、东南亚、印度的合规、语言、渠道几乎没有共性。
  • 不把 GitHub star 当采用度。本月至少 4 个样本存在明显刷星/营销疑点，先看下载与 issue。

2026 年 Q4，AI 的稀缺资源已经从“模型能力”转向“可验证的交付”和“可审计的信任”。在亚洲，谁能把这两件事同时做成产品，谁就能拿到溢价。
